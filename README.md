
# 🎵 Music Player UI (HTML & CSS Only)

## 📌 Project Description

This project is a **Music Player User Interface (UI)** created using **only HTML and CSS**.
It focuses purely on **front-end design and layout**, without using **JavaScript**, backend logic, or any external frameworks.

The project demonstrates how a visually appealing music player interface can be designed using **basic web technologies**.
